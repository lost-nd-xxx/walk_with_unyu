# 作業応援うにゅう

* 回し車を回すうにゅうが、あなたの作業を応援するゴーストです。
* 指定されたファイルの保存回数やファイルサイズの増減を見守ります。
* 見守り対象のファイルが作業中に一定時間更新されなかった場合、保存をおすすめしたりもします。

* 作者 : ろすえん（lost_nd_xxx）
* https://lnx.flop.jp/

このファイルセットは伺か（ukagaka）のゴーストです。
動かすには、SSP（ https://ssp.shillest.net/ ）などのベースウェアが必要です。

## ライセンス

### このゴーストのオリジナル部分

辞書（`ghost/master/dic/normal/`、`ghost/master/dic/emerg/`）とシェル（`shell/master/`）は、ろすえん（lost_nd_xxx）が権利を持ちます。

**事前の連絡をお願いするもの**

* 再配布
* 改変したものの配布

**ご自由にどうぞ（出典表記は任意です）**

* スクリーンショットの投稿、動画配信
* 二次創作（イラスト、小説など）
  * ただし、このゴーストのファイル（画像・辞書）そのものを含めないでください。
* 追加シェルの作成と、その配布
  * `shell/master/surfaces.txt` と `shell/master/surfacetable.txt` に限り、転用・改変を許可します（画像ファイルは含みません）。

### 「うにゅう」というキャラクターについて

「うにゅう」は、伺かの原型である「偽春菜（後のMateria）」に登場した相方キャラクターに由来します。このゴーストはその二次創作にあたります。
シェルの画像はテンプレート由来のファイルを含まない自作ですが、キャラクターの概念そのものは借りているものです。

このゴーストには、第三者が権利を持つファイルが含まれます。それぞれ本来のライセンスに従ってください。
